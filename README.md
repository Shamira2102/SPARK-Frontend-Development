## 📖 Overview

**SPARK-Frontend-Development** is a responsive frontend webpage built for **SPARK 2026**. It features an animated canvas background, a clear event schedule, and an interactive registration form with department and role selection, an event checklist, and form validation, giving participants a smooth and visually engaging experience.

## ✨ Features

| Feature | Description |
| 🎆 **Animated Canvas Background** | Dynamic, eye-catching visuals powered by the HTML5 Canvas API |
| 📅 **Event Schedule** | Clear, easy-to-read timeline of all SPARK 2026 events |
| 📝 **Registration Form** | Interactive form for participant sign-up |
| 🏫 **Department Selection** | Choose your department from a dropdown |
| 🎭 **Role Selection** | Pick your participation role |
| ✅ **Event Checklist** | Select the events you want to join |
| 🛡️ **Form Validation** | Real-time validation to prevent incorrect or incomplete submissions |
| 📱 **Responsive Design** | Works across mobile, tablet, and desktop screens |

---

## 🛠️ Tech Stack

- **HTML5**: page structure and form elements
- **CSS3**: styling, layout, and responsiveness
- **JavaScript (Vanilla)**: canvas animation, form logic, and validation
- **GitHub Pages**: hosting and deployment

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/shamira2102/SPARK-Frontend-Development.git

# 2. Move into the project folder
cd SPARK-Frontend-Development

# 3. Open index.html in your browser
```

> 💡 No installation or build step needed, just open `index.html`.
